# hexwatershed_utility
A collection of tools for HexWatershed pre and post processing


The HexWatershed model supports various hydrologic features in its flow direction modeling workflow. Many of these features can also be directly burned into the computational mesh. However, these features usually require pre-processing so that they are be directly incorporated into the mesh. For example, the river networks may need to simplified to a certain level of detail to match the mesh resolution.
